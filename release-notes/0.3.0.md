**Linux** — `refryt-0.3.0-x86_64.AppImage`: download, `chmod +x`, run. Or use
`scripts/appimage-install.sh install` from source for a desktop launcher entry.

**Linux, Flatpak** — `flatpak install --user https://gridoe.github.io/refryt/refryt.flatpakref`,
then `flatpak run io.github.gridoe.refryt`; updates come with `flatpak update`. The file
`refryt-0.3.0-x86_64.flatpak` installs the same build and updates from the same repo. It
needs the GNOME 51 runtime, which Flatpak offers to fetch the first time. mpv and yt-dlp are
inside. The sandbox can't see your browsers' profile folders, so "Import from a browser" is hidden
and you sign in through the app's own window; "Launch on startup" is hidden too, since a sandboxed
app can't write a login item.

**Windows** — three options for x64, and two for ARM, cross-compiled from Linux with limited testing on real Windows
hardware:
- `refryt-0.3.0-windows-x86_64-setup.exe` — a real installer (Program Files, Start Menu,
  uninstaller). Unsigned, so SmartScreen will warn on first run — expected, not a bug.
- `refryt-0.3.0-windows-x86_64.msi` — the same files as an MSI, for deployment tools or a
  silent install (`msiexec /i refryt-0.3.0-windows-x86_64.msi /qn`). It installs to the same
  folder as the setup, so use one or the other.
- `refryt-0.3.0-windows-x86_64.zip` — portable, no install: unzip and run `refryt.exe`.
  Extract the whole folder before running; the exe needs the DLLs beside it.
- `refryt-0.3.0-windows-arm64.msi` / `.zip` — a native build for Windows on ARM, not yet tested
  on ARM hardware. The x64 files also run there under emulation.

**macOS** — `refryt-0.3.0-macos-arm64.dmg`, for Apple Silicon only. Open it and drag
Refryt to Applications. It is signed ad hoc and not notarized, so
macOS will refuse to open it on the first launch. Run `xattr -cr /Applications/Refryt.app` once,
or allow it in System Settings → Privacy & Security. libmpv and yt-dlp are bundled; nothing needs
installing.

Checksums for every file are in `refryt-0.3.0-SHA256SUMS.txt`.

What changed since 0.2.2:

- **Listening stats** — a Stats page from a log kept on this computer: top songs, artists and
  albums, time listened, a calendar and plays over time, from today back to all time. A song
  counts once 30 seconds of it have played, or half of it if that is shorter. Turning stats off
  in Settings also hides the Stats button.
- **History from before refryt** — a Google Takeout export brings in the account's whole
  listening history with exact times. Importing a newer export later adds only what is new, and
  a play logged in refryt is not counted twice.
- **Plays on other devices** — the account's history is checked when refryt starts, when Stats
  opens and every 10 minutes, and songs played elsewhere are added to Stats with estimated
  times.
- **Song cache** — off by default, in Settings > Playback > Cache (#23). Songs are kept on disk
  as they stream, with nothing downloaded twice, so a cached song starts at once and plays
  without a connection. Replaying one fetched 0.95 MB in a test, against about 9.4 MB
  streaming it. The size goes from 250 MB to no limit, 10 GB by default, and the songs played
  longest ago make room for new ones.
- **Cover colour** — the now-playing view shows a toned-down blurred cover, and album, playlist
  and artist headers fade in the cover's colour (#22). Settings > Appearance > Adaptive colour
  turns both off.
- **Now playing** — the queue sits on the right when lyrics are off, the layout no longer jumps
  when the window changes size, and F11 is instant from a window that already fills the screen.
- **Tray** — a click on the Windows tray icon shows or hides the window, a middle click does
  the same on Linux, and on Sway the window hides to the scratchpad (#25, by 9M2PJU).
- **Sliders** — the sliders in Settings have marks under the track and no longer shift while
  being dragged.
- **What's new** — this list opens once after each update, and from the ? beside the version
  in Settings > About, next to a link to the GitHub page.
