**Linux** — `refryt-0.3.3-x86_64.AppImage`: download, `chmod +x`, run. Or use
`scripts/appimage-install.sh install` from source for a desktop launcher entry.

**Linux, Flatpak** — `flatpak install --user https://gridoe.github.io/refryt/refryt.flatpakref`,
then `flatpak run io.github.gridoe.refryt`; updates come with `flatpak update`. The file
`refryt-0.3.3-x86_64.flatpak` installs the same build and updates from the same repo. It
needs the GNOME 51 runtime, which Flatpak offers to fetch the first time. mpv and yt-dlp are
inside. The sandbox can't see your browsers' profile folders, so "Import from a browser" is hidden
and you sign in through the app's own window; "Launch on startup" is hidden too, since a sandboxed
app can't write a login item.

**Windows** — three options for x64, and two for ARM, cross-compiled from Linux with limited testing on real Windows
hardware:
- `refryt-0.3.3-windows-x86_64-setup.exe` — a real installer (Program Files, Start Menu,
  uninstaller). Unsigned, so SmartScreen will warn on first run — expected, not a bug.
- `refryt-0.3.3-windows-x86_64.msi` — the same files as an MSI, for deployment tools or a
  silent install (`msiexec /i refryt-0.3.3-windows-x86_64.msi /qn`). It installs to the same
  folder as the setup, so use one or the other.
- `refryt-0.3.3-windows-x86_64.zip` — portable, no install: unzip and run `refryt.exe`.
  Extract the whole folder before running; the exe needs the DLLs beside it.
- `refryt-0.3.3-windows-arm64.msi` / `.zip` — a native build for Windows on ARM, not yet tested
  on ARM hardware. The x64 files also run there under emulation.

**macOS** — `refryt-0.3.3-macos-arm64.dmg`, for Apple Silicon only. Open it and drag
Refryt to Applications. It is signed ad hoc and not notarized, so
macOS will refuse to open it on the first launch. Run `xattr -cr /Applications/Refryt.app` once,
or allow it in System Settings → Privacy & Security. libmpv and yt-dlp are bundled; nothing needs
installing.

Checksums for every file are in `refryt-0.3.3-SHA256SUMS.txt`.

What changed since 0.3.2:

- **Lyrics from seven sources** — BetterLyrics, lrc.red, LRCLIB, KuGou, Unison and YouTube Music
  (synced and plain) are asked at once, and the first synced answer in your order is shown.
  Lyrics sources in Settings → System sets the order and which sources are used, and the lyrics panel can
  switch to another source's answer for the song that's playing. Genius is no longer a source.
- **Romanised lyrics** — for Japanese, Korean and Chinese songs, lyrics with a romanisation are
  preferred, with the original under each line. On by default; turn it off with "Prefer
  romanised lyrics" in Settings → System.
- **Artist and song stats** — a page for every artist and song you play: plays, listening time,
  first and last played, your rank all-time and over 6 months, most plays in a day, your top
  songs and first song by an artist, and plays by month. Open one from Stats' top lists,
  "Your stats" in a song's menu, or the new stats button on an artist page.
- **Artist pages** — the line under the name says where they rank for you ("Your #2 artist",
  "Your #3 artist this month"), or else your total plays.
- **Themes** — macOS, Windows and Breeze (light and dark), and on Linux, GTK and Qt themes that
  follow your desktop's colours. A fresh install starts on the theme that matches your system.
- **Fixes** — the GTK colours are read only when you use the GTK theme or have Settings open,
  instead of at every start and focus change; quitting while they were being read no longer leaves
  a crash report behind. The album page's play icon sits over the track number on hover, and
  settings rows keep their spacing under long descriptions.
